## 교과서·수업 사이트 정리 기준

- PDF 교과서의 대단원과 소단원 명칭을 폴더명으로 사용했습니다.
- `사이트_예제`에는 [yubs.online/java](http://yubs.online/java/)의 코드 블록 412개를 원문 페이지별 Markdown으로 보존했습니다. 개념 메모와 Java 코드가 함께 있는 원문 구조도 유지했습니다.
- 실행 가능한 Light.IDE 예제는 해당 교과서 소단원에 `.java` 파일로 배치했습니다.
- 교과서 범위를 벗어나거나 여러 단원을 복습하는 실행 예제는 과목명이 아닌 `자습/` 아래에 둡니다.

## 원본 보존 및 제외 기준

원본을 임의로 고쳐서 실행 가능하게 만들지 않았습니다. 다음 Light.IDE 파일은 현재 상태에서 컴파일되지 않거나 의존 클래스가 없어 `자습/미완성_원본`에 원문 그대로 보존했습니다.

- `UnicodePrint.java`: 닫는 중괄호가 누락된 미완성 소스
- `Java/CircleWithFinal`: 클래스 선언 밖의 생성자와 문법 오류가 있는 미완성 소스
- `Java/CilStudy.java`: `main` 메서드가 닫히지 않은 미완성 소스
- `Java/Child.java`: private 필드 접근과 누락된 세미콜론이 있는 설명용 미완성 소스
- `Java/PublicPersonDemo.java`: `PublicPerson` 의존 클래스가 원본에 없음
- `Java/PersonWithStaticDemo`: `PersonWithStatic` 생성자의 필수 인자를 전달하지 않아 컴파일 불가
- `ArrayDemo.java`: `dArr, length` 호출의 식별자 오류가 있어 교과서 배열 단원에는 보존하되 실행 예제로는 제외
