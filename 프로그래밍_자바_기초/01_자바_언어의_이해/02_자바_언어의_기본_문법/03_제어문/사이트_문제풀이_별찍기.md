## 코드 블록 2

```text
import java.util.Scanner;

public class StarRect {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("행(N) : ");
        int n = sc.nextInt();
        System.out.print("열(M) : ");
        int m = sc.nextInt();
        for (int i = 1; i <= n; i++) {
            for (int j = 1; j <= m; j++) {
                System.out.print("*");
            }
            System.out.println();
        }
        sc.close();
    }
}
```

            for (int j = 1; j <= mid - i; j++) {

        int n = sc.nextInt();
