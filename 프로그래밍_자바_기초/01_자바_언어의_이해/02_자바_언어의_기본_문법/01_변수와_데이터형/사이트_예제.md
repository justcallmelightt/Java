## 코드 블록 3

```text
# 10진법 (Decimal)

우리가 일상에서 사용하는 진법, 0~9 사용

# 2진법 (Binary)

0과 1만 사용, 컴퓨터가 내부적으로 데이터를 표현하는 방식

## 10진수를 2진수로 변환

10진수 → 2진수 (나누기)
13 ÷ 2 = 6 ... 1
 6 ÷ 2 = 3 ... 0
 3 ÷ 2 = 1 ... 1
 1 ÷ 2 = 0 ... 1
아래서 위로 읽기 → 1101

## 2진수를 10진수로 변환

2진수 → 10진수 (자릿값)
1101
= 1×2³ + 1×2² + 0×2¹ + 1×2⁰
= 8 + 4 + 0 + 1
= 13

# 16진법 (Hexadecimal)

0~9, A~F 사용, 2진수 4자리 = 16진수 1자리

## 10진수를 16진수로 변환

10진수 → 16진수 (나누기)
255 ÷ 16 = 15 ... 15 (F)
 15 ÷ 16 =  0 ... 15 (F)
아래서 위로 읽기 → FF

## 16진수를 10진수로 변환

16진수 → 10진수 (자릿값)
FF
= 15×16¹ + 15×16⁰
= 240 + 15
= 255
```

## 코드 블록 5

```text
public class TypeCastingDemo {
    public static void main(String[] args) {
        // 1. 자동 형변환 (작은 타입 → 큰 타입)
        int i = 100;
        long l = i;            // int → long
        double d = i;          // int → double
        System.out.println(l); // 100
        System.out.println(d); // 100.0

        // 2. 정수 + 실수 혼합 연산 (int → double 자동 변환)
        int a = 3;
        double b = 1.5;
        double result = a + b;      // a가 3.0으로 자동 변환
        System.out.println(result); // 4.5

        // 3. 강제 형변환 (큰 타입 → 작은 타입, 데이터 손실 가능)
        int big = 300;
        byte small = (byte) big;   // 하위 1바이트만 남음
        System.out.println(small); // 44 (300의 하위 8비트)

        // 4. 실수 → 정수 강제 형변환 (소수점 버림)
        double pi = 3.14159;
        int piInt = (int) pi;
        System.out.println(piInt); // 3 (소수점 이하 버림)

        // 5. int → float 자동 형변환 (정밀도 손실 주의)
        int precise = 123456789;
        float f = precise;  // 자동 형변환이지만 정밀도 손실 발생
        System.out.println(precise); // 123456789
        System.out.println(f);       // 1.23456792E8 (미세하게 다름!)

        // 6. byte + byte 연산 => 결과는 int
        byte b1 = 10;
        byte b2 = 20;
        // byte b3 = b1 + b2;      // 컴파일 에러! 결과가 int
        byte b3 = (byte)(b1 + b2); // 강제 형변환 필요
        System.out.println(b3);    // 30

        // 7. 정수 나눗셈 (소수점 버림 주의)
        int x = 7;
        int y = 2;
        System.out.println(x / y);         // 3 (소수점 버림!)
        System.out.println((double)x / y); // 3.5 (캐스팅 후 나눗셈)

        // 8. char → int 자동 형변환 (유니코드 값)
        char c = 'A';
        int unicode = c;
        System.out.println(unicode); // 65 (A의 유니코드)

        // 9. int → char 강제 형변환
        int code = 66;
        char ch = (char) code;
        System.out.println(ch); // B
    }
}
```

```text
# Signed (부호 있음)

- 양수 + 음수 모두 표현
- 맨 앞 1비트를 부호 비트로 사용 (0=양수, 1=음수)

- 양수만 표현, 대신 범위가 2배
- 부호 비트까지 값으로 사용
- C, C++ 등에서는 unsigned int로 직접 명시 가능

# Java는?

- 기본적으로 unsigned 정수형 없음 (char 제외 — 0~65,535)
- Java 8부터 Integer.toUnsignedString() 등 unsigned 처리 유틸 메서드 추가
- 실무에서 필요한 경우 long으로 올려서 처리하는 게 일반적

signed int   : -2,147,483,648  ~  2,147,483,647
unsigned int :              0  ~  4,294,967,295
```

## 코드 블록 9

```text
# 개념

- 정수형 변수는 저장할 수 있는 값의 범위가 정해져 있음
- 그 범위를 벗어나면 반대쪽 끝값으로 wrap-around 되는 현상 발생
- 오류가 발생하는 게 아니라 조용히 잘못된 값이 들어가기 때문에 더 위험

# 오버플로우 (Overflow)

- 최댓값을 초과했을 때 발생
- 최댓값 + 1 → 최솟값으로 넘어감
- 예: int 기준 2,147,483,647 + 1 = -2,147,483,648

# 언더플로우 (Underflow)

- 최솟값 미만으로 내려갔을 때 발생
- 최솟값 - 1 → 최댓값으로 넘어감
- 예: int 기준 -2,147,483,648 - 1 = 2,147,483,647

# 왜 이렇게 동작하나?

- 정수는 내부적으로 2진수 비트로 저장됨
- 비트가 꽉 찬 상태에서 +1 하면 맨 앞 비트(부호 비트)가 뒤집히면서 음수로 바뀌는 원리
- 시계처럼 12 다음이 1로 돌아오는 것과 같은 구조

# 주의할 타입

- byte  :         127 초과 → -128
- short :      32,767 초과 → -32,768
- int   : 2,147,483,647 초과 → -2,147,483,648
- long  : 범위가 매우 크지만 동일한 원리로 적용됨

# 실무에서 왜 중요한가

- 컴파일 오류도, 런타임 예외도 발생하지 않음 → 디버깅이 매우 어려움
- 대용량 데이터 곱셈, 누적 카운터 등에서 실수하기 쉬움
- 범위 초과가 예상되면 더 큰 타입(int → long)으로 올려야 함
- 실제 사례: 유튜브 조회수가 int 범위를 초과해 음수로 표시된 버그 발생 (2014년 Gangnam Style)
```

## 코드 블록 10

```text
public class OverUnderFlowDemo {
    public static void main(String[] args) {
        // 1. int 오버플로우 - 최댓값에서 +1
        int maxInt = Integer.MAX_VALUE; // 2,147,483,647
        System.out.println("int 최댓값: " + maxInt);
        System.out.println("최댓값 + 1: " + (maxInt + 1)); // -2,147,483,648 (음수로 wrap!)
        System.out.println();

        // 2. int 언더플로우 - 최솟값에서 -1
        int minInt = Integer.MIN_VALUE; // -2,147,483,648
        System.out.println("int 최솟값: " + minInt);
        System.out.println("최솟값 - 1: " + (minInt - 1)); // 2,147,483,647 (양수로 wrap!)
        System.out.println();

        // 3. byte로 더 짧게 체감
        byte b = 127;
        System.out.println("byte 최댓값: " + b);
        b++;
        System.out.println("127 + 1 = " + b); // -128
        System.out.println();

        // 4. 실무 사고 사례 - 대용량 곱셈
        int views1 = 1_000_000;
        int views2 = 1_000_000;
        System.out.println("int 곱셈 결과: " + (views1 * views2));        // 오버플로우!
        System.out.println("long 곱셈 결과: " + ((long)views1 * views2)); // 정상
    }
}
```
