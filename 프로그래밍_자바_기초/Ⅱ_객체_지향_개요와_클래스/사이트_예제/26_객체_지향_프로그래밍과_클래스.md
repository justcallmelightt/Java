## 코드 블록 1

```text
# 절차 지향 (Procedural Programming)

- 실행할 명령어를 순서대로 나열하는 방식
- 레시피처럼 1번 → 2번 → 3번 순서로 처리
- 대표 언어: C, Pascal

# 객체 지향 (Object-Oriented Programming, OOP)

- 프로그램을 독립적인 객체들의 상호작용으로 구성하는 방식
- 레고 블록처럼 독립적인 부품(객체)을 조립해서 완성
- 대표 언어: Java, C++, Python, Ruby
```

## 코드 블록 3

```text
객체는 현실 세계에서 관찰할 수 있는 사물이나 개념을 프로그램의 기본 단위로 표현한 것

객체는 두 가지 요소로 구성된다
- 상태 (State)    : 객체가 가진 정보/속성       →  Java에서 필드(field)
- 행동 (Behavior) : 객체가 수행할 수 있는 동작  →  Java에서 메서드(method)

# 예시: 자동차 객체

상태 (필드)     행동 (메서드)
모델            출발하다
색상            속도를 올리다
속도            속도를 줄이다
제조회사        정지하다
```

## 코드 블록 4

```text
클래스는 객체를 만들기 위한 틀(설계도)이다

- 클래스 : 설계도  →  붕어빵 틀, 자동차 설계도
- 객체   : 실체    →  붕어빵, 실제 자동차

같은 클래스로 만든 객체들은 같은 구조(상태/행동)를 가지지만, 각자 독립적인 값을 가진다
클래스는 하나지만 객체는 여러 개 만들 수 있다
```

# Java는 "완전한 OOP 언어"가 아니다

- int, double 같은 기본형(primitive type)은 객체가 아님
- Ruby, Smalltalk 같은 완전한 OOP 언어에서는 숫자도 객체
- 엄밀히는 "OOP를 강하게 지원하는 언어"가 더 정확한 표현
- 나중에 Integer vs int 래퍼 클래스 단원과 연결됨
